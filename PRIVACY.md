# Privacy Policy for NElement

NElement is a Chrome extension for inspecting visible page elements, testing responsive page sizes, copying frontend details, and capturing the visible page area from the active browser tab.

## Data Collection

NElement does not collect, sell, transfer, or transmit user data to external servers.

The extension runs locally in the browser. Element details, selectors, JSON output, screenshots, and responsive resize actions are generated only when the user starts the inspector, capture, or resize workflow.

## Clipboard Usage

NElement can copy selectors, JSON inspection details, or captured images to the clipboard only after the user chooses a copy action or uses a capture shortcut.

## Website Content

NElement reads page content only to inspect the element selected by the user and to capture the visible area of the active tab. This information remains on the user's device unless the user manually copies, downloads, or shares it.

## Permissions

NElement requests browser permissions only for its core purpose:

- Inspecting page elements on websites where the user activates the extension.
- Injecting the local inspector interface into the active page.
- Capturing the visible area of the active tab when requested by the user.
- Showing a centered responsive preview frame when the user chooses a preset or custom size.
